# QuizForge

> A modern quiz application for creating and taking interactive quizzes.

QuizForge is a responsive quiz application built with React and TypeScript, focused on interactive question flows, clear feedback and a clean user experience.

🌐 **Live Demo:** https://mahsanasiry.github.io/quizforge/

## Features

- Interactive quiz experience
- Multiple-choice questions
- Answer selection and feedback
- Score tracking
- Quiz progress indicator
- Responsive layout
- Accessible interface
- Clear loading and error states
- Reusable UI components

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- GitHub Actions
- GitHub Pages

## Project Highlights

QuizForge was built as a practical front-end project with a focus on:

- Component-based development
- Type-safe development with TypeScript
- Interactive application state
- Responsive design
- Accessible user interfaces
- Reusable components
- Clean and maintainable code
- Static deployment with GitHub Actions
